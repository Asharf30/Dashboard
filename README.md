# Dashboard (React + Vite)

A simple dashboard project built with React and Vite for UI screens, reports, and data views.
Includes animations with Framer Motion and UI/charts components from Syncfusion.

## Live Demo

- https://dashboard-ashraf.netlify.app

## Quick Features

- Clean, organized dashboard layout.
- Reusable UI components.
- Multiple pages (analytics, customers, orders, calendar, and more).
- Smooth animations using Framer Motion.
- Charts and UI widgets powered by Syncfusion.



## Project Structure (Simple)

```text
dashboard/
├─ public/
├─ src/
│  ├─ components/      # UI components
│  ├─ context/         # app state and context provider

│  ├─ main.jsx
│  └─ index.css

```
